# Provenance and public-release boundary

The telemetry equations and shared calibration values were extracted from the
research code supplied for the Acquisition-State Telemetry paper. The public
binding layer was rewritten to expose a small interface and a common JSONL
trajectory contract.

The dialogue and kinematic evidence are synthetic. The default dialogue
representation is generated by the real local Ollama model
`qwen3-embedding`; hash vectors are retained only for CI and smoke testing.

No participant data, complete experimental corpus, checkpoints, private scorer
outputs, machine-specific paths, or under-review result files are included.
